Gemini-based agent framework

Build agents from first principles.

agentic-ai-kit is a progressive Python framework for building conversational agents, tool-using agents, structured-output agents, dataframe agents, long-term memory systems, RAG workflows, MCP-style tools, multi-agent patterns, and SQL AI enrichment over SQLite.

Quickstart

The simplest agent is a BaseAgent. It wraps a Gemini model with a name, system prompt, optional memory behavior, and a think() method. 

import os

from agentic_ai.agents import BaseAgent


if not os.getenv("GEMINI_API_KEY"):
    raise EnvironmentError("Set GEMINI_API_KEY before running this example.")


agent = BaseAgent(
    name="Alfred",
    sys_prompt="You are a witty British butler.",
    model="gemini-2.5-flash-lite",
    extract_memory=False,
)

response = agent.think(
    "Good morning. What should I focus on today?",
    stream=False,
)

print(response)

Modules

The kit is organized around composable agent primitives instead of one heavy abstraction.

Agents

Conversational, tool-using, JSON, reasoning, analyst, MLE, and AutoModel agents.

Memory

Short-term conversation state, durable facts, shared memory, and SQLite-backed long-term memory.

SQL AI

Use Gemini pseudo-functions inside SQLite-style queries to enrich rows with summaries, labels, and keywords.

RAG

Chunk text, embed it, store vectors, retrieve context, and answer with retrieved material.

Tools

Register Python functions and expose them to Gemini function calling.

MCP

Minimal MCP-style local server/client pattern for exposing tools over HTTP.

Constructors and API reference

This section documents the main public classes and functions.

BaseAgent

The foundation for all agents.

agentic_ai.agents 
from agentic_ai.agents import BaseAgent

BaseAgent(
    name: str,
    sys_prompt: str,
    model: str = "gemini-2.5-flash-lite",
    api_key: str | None = None,
    memory_window: int = 3,
    max_turns: int | None = None,
    max_facts: int = 50,
    extract_memory: bool = True,
    thinking_budget: int = 0,
)
Parameter Meaning
nameDisplay name of the agent.
sys_promptSystem prompt/persona used by Gemini.
modelGemini model name.
api_keyOptional Gemini API key. If omitted, reads GEMINI_API_KEY.
memory_windowNumber of recent turns included in memory context.
max_turnsOptional maximum number of retained conversation turns.
max_factsMaximum durable facts retained in the in-agent fact store.
extract_memoryWhether to extract durable facts from user messages.
thinking_budgetGemini thinking budget where supported.

Runnable example

from agentic_ai.agents import BaseAgent

agent = BaseAgent(
    name="Sage",
    sys_prompt="You are concise, clear, and practical.",
    model="gemini-2.5-flash-lite",
    extract_memory=False,
)

response = agent.think(
    "Explain Python classes with one example.",
    stream=False,
)

print(response)

Register a tool

agent.register_tool(
    fn,

    params: dict | None = None,

)

Runnable example

from agentic_ai.agents import ToolAgent


def calculate_rectangle_area(length: float, width: float) -> float:
    return length * width


agent = ToolAgent(
    name="Calculator",
    sys_prompt="Use tools whenever exact calculation is required.",
)

agent.register_tool(calculate_rectangle_area)

response = agent.think(
    "What is the area of a rectangle that is 12.5 metres long and 8 metres wide?"
)

print(response)

AnalystAgent

DataFrame-aware analytics specialist.

agentic_ai.agents 
from agentic_ai.agents import AnalystAgent

AnalystAgent(
    name: str = "Analyst",
    domain_context: str | None = None,
    model: str = "gemini-2.5-flash-lite",
    api_key: str | None = None,
    memory_window: int = 3,
    max_turns: int | None = None,
    thinking_budget: int = 0,
)

Main methods

MethodPurpose
profile_dataframe(df)Rows, columns, dtypes, missing values, duplicates.
numeric_summary(df)Numeric describe summary.
categorical_summary(df, top_n=10)Top category counts.
groupby_summary(df, group_col, metric_col, agg="mean")Grouped metric summary.
correlation_summary(df)Numeric correlation matrix.
analyze_dataframe(df, question, stream=True)Creates dataframe context and asks the agent to analyze it.

Runnable example

import pandas as pd
from agentic_ai.agents import AnalystAgent

df = pd.DataFrame({
    "segment": ["A", "A", "B", "B"],
    "sales": [100, 140, 80, 120],
})

agent = AnalystAgent(
    domain_context="Simple sales analysis.",
)

print(agent.profile_dataframe(df))
print(agent.groupby_summary(df, "segment", "sales", agg="mean"))

answer = agent.analyze_dataframe(
    df,
    "Which segment has higher average sales?",
    stream=False,
)

print(answer)

LongTermMemory

SQLite-backed persistent memory.

agentic_ai.memory 
from agentic_ai.memory.long_term import LongTermMemory

LongTermMemory(
    db_path: str | Path = "long_term_memory.db",
)

Methods

MethodPurpose
log(content, agent="unknown")Append a memory entry and return its row id.
search(keyword, agent=None, limit=20)Search memory content using SQL LIKE.
recent(n=10, agent=None)Return recent memory entries.
clear(agent=None)Delete memory entries.
close()Close the SQLite connection.

Runnable example

from agentic_ai.memory.long_term import LongTermMemory

memory = LongTermMemory("agent_memory.db")

memory.log(
    "User is building agentic-ai-kit.",
    agent="project",
)

memory.log(
    "SQL AI enriches SQLite rows with Gemini-generated columns.",
    agent="project",
)

results = memory.search("SQL AI", agent="project")

for row in results:
    print(row)

memory.close()

SQL AI

Gemini-generated columns inside local SQLite-style queries.

agentic_ai.sql_ai 
from agentic_ai.sql_ai import run_ai_sql, parse_ai_sql

run_ai_sql(
    sql: str,
    conn,
    api_key: str | None = None,
    batch_size: int = 15,
    workers: int = 4,
    default_model: str = "gemini-2.5-flash",
    temperature: float = 0.3,
    top_p: float = 0.95,
    max_output_tokens: int = 8192,
    write_if_create: bool = True,
)

Supported pseudo-functions

ai_generate(prompt='...', model='...') AS generated_text

ai_summarize(model='...') AS summary

ai_classify(labels='A | B | C', model='...') AS label

ai_extract(prompt='Extract retrieval keywords', count=5, model='...') AS keywords

Runnable example

import os
import sqlite3
import pandas as pd

from agentic_ai.sql_ai import run_ai_sql


if not os.getenv("GEMINI_API_KEY"):
    raise EnvironmentError("Set GEMINI_API_KEY before running this example.")


conn = sqlite3.connect(":memory:")

records = pd.DataFrame({
    "record_id": [1, 2, 3],
    "topic": ["Access", "Documentation", "Automation"],
    "notes": [
        "User cannot access account after changing password.",
        "Setup instructions are unclear and need examples.",
        "Incoming messages should be classified automatically.",
    ],
})

records.to_sql("records", conn, if_exists="replace", index=False)

sql = """
SELECT
    record_id,
    topic,
    notes,
    ai_generate(
        prompt='Write a short retrieval-friendly summary for this row',
        model='gemini-2.5-flash'
    ) AS retrieval_summary
FROM records
"""

result = run_ai_sql(
    sql=sql,
    conn=conn,
    batch_size=2,
    workers=2,
)

print(result)

Write result back to SQLite

sql = """
CREATE OR REPLACE TABLE enriched_records AS
SELECT
    record_id,
    notes,
    ai_summarize(model='gemini-2.5-flash') AS summary,
    ai_extract(
        prompt='Extract retrieval keywords from this row',
        count=5,
        model='gemini-2.5-flash'
    ) AS retrieval_keywords
FROM records
"""

result = run_ai_sql(sql=sql, conn=conn)

saved = pd.read_sql_query("SELECT * FROM enriched_records", conn)

print(saved)

RAGAgent

Retrieves relevant chunks from a vector store before answering.

agentic_ai.rag 
from agentic_ai.rag.rag_agent import RAGAgent

RAGAgent(
    name: str,
    sys_prompt: str,
    top_k: int = 3,
    **kwargs,
)

Methods

MethodPurpose
ingest(text, chunk_size=500, overlap=50)Chunk and embed text into the vector store.
think(input_text, use_memory=True, stream=True)Retrieve context and answer using the base agent.

Example

from agentic_ai.rag.rag_agent import RAGAgent

agent = RAGAgent(
    name="DocsBot",
    sys_prompt="Answer only using retrieved context.",
    top_k=3,
)

agent.ingest("""
agentic-ai-kit supports BaseAgent, ToolAgent, LongTermMemory,
SQL AI, RAG, MCP, and multi-agent patterns.
""")

response = agent.think(
    "What modules does agentic-ai-kit support?",
    stream=False,
)

print(response)

MCP-style tools

Minimal local HTTP tool server and client.

agentic_ai.mcp 
from agentic_ai.mcp.server import MCPServer
from agentic_ai.mcp.client import MCPClient

MCPServer(
    host: str = "localhost",
    port: int = 8765,
)

MCPClient(
    base_url: str = "http://localhost:8765",

Server example

from agentic_ai.mcp.server import MCPServer

server = MCPServer(port=8765)

@server.tool
def echo(message: str) -> str:
    return message

server.run()

Client example

from agentic_ai.mcp.client import MCPClient

client = MCPClient("http://localhost:8765")

print(client.list_tools())
print(client.call("echo", message="hello"))
